# TurtleCross-Python

A fun arcade-style game where a turtle tries to cross a road filled with moving cars without getting hit!  
Built using Python’s `turtle` module as part of my 100 Days of Python journey.

---

## 🎮 Game Features

✅ Player controls a turtle using the keyboard  
✅ Randomly generated cars move from right to left  
✅ Collision detection ends the game if the turtle gets hit  
✅ Score increases when the turtle reaches the top safely  
✅ Speed increases as levels progress

---

## 🚀 How to Play

- Press the **Up Arrow** (⬆️) to move the turtle forward  
- Avoid the cars  
- Reach the top of the screen to score  
- Survive as long as you can!
